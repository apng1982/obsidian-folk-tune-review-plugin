# New Folk Tunes Vault

You can delete this file once you're done with it!

## Next steps

- Update the templates with any additional information you'd like copied into new tunes/set/composers/etc.
- You can delete the same tunes, set and dots - they're just there as an example.
- Add any origins, types or other metadata you'd like to use in your database.
- Start populating the vault with all your tunes and sets!
    - You can use the `Add Tune` command to add a new tune to the vault.
    - You can use the `Add Set` command to add a new set to the vault.
    - You can use the `Add Composer` command to add a new composer to the vault.


## Start reviewing your tunes

- On a windows machine, you can press Ctrl + P to open the command palette.
- On a mobile, drag down from the top of the screen to see all options.

- Type "folk tune" to see all available options.
  - `Start Review` is a full review
  - `Add review to current tune` can add review data to the currently opened tune
  - `Show stats` shows some useful stats about all the tunes in your vault
